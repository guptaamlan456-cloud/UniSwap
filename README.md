# UniSwap

UniSwap is a marketplace platform developed for international students in Malaysia who are moving out, graduating, or returning to their home countries. The platform helps students buy and sell second-hand products such as furniture, electronics, textbooks, kitchen appliances, gaming accessories, and other daily-use items.

The main objective of the project was to create a simple and modern platform where students can quickly sell items before leaving the country or moving to a differnt city while helping other students find affordable products nearby.

---

# Project Overview

This project was developed as a full-stack web application using Flask and PostgreSQL. The platform includes user authentication, listing management, image uploads, filtering, search functionality, urgency indicators, and an in-app messaging system between buyers and sellers.

The project was later converted into an Android APK using Flutter WebView so it could also function as a mobile application.

---

# Main Features

- User registration and login system
- Create, edit, and delete product listings
- Multiple image upload support
- Product search and filtering
- Area and category filtering
- In-app buyer and seller messaging
- Urgency indicators for listings
- Responsive UI design
- Android APK support using Flutter
